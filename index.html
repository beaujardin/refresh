Aperçus intégrés
Aide
  • + Ajouter une page ajoute une page (autant de fois que tu veux : un clic = une page, donc le bloqueur de popups ne se déclenche jamais). Démarrer lance le rafraîchissement ; il devient Arrêter pendant la session.
  • Mode « Intégré » : chaque page s'affiche dans un petit cadre en bas de cette page, sans nouvelle fenêtre ni onglet. Pratique pour en ajouter beaucoup. Attention : certains sites interdisent l'affichage en cadre (X-Frame-Options) et resteront vides — dans ce cas, utilise les modes Onglets ou Fenêtres.
  • Mode Onglets / Fenêtres : ouvre de vraies pages ; « Fermer les pages » les referme. L'URL est verrouillée pendant le rafraîchissement.
  • Le rafraîchissement est piloté par cet onglet : garde-le ouvert. « Garder actif » empêche le navigateur de ralentir les timers quand l'onglet passe en arrière-plan.
  • Le navigateur plancher les timers à ~4 ms : « 1 ms » donne ~4 ms en pratique.
  • Pour autoriser les popups (modes Onglets/Fenêtres) : Chrome / Edge icône « Popups bloqués » → « Toujours autoriser les popups pour ce site » ; Firefox icône « Popups bloqués » → « Autoriser les popups pour ce site » ; Safari Réglages → Sites web → Fenêtres pop-up → Autoriser.
